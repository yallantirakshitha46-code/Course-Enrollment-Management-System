# Course Enrollment Management System

A console-based Course Enrollment Management System developed using Java.

## Features
- Student registration
- Course management
- Student enrollment and cancellation
- Course capacity management
- Enrollment reports
- File handling for data storage

## Technologies Used
- Java
- Object-Oriented Programming
- File Handling
- Collections Framework

## Project Structure
- Admin
- Student
- Course
- Enrollment
- CourseService
- FileManager
- Main

## How to Run
1. Clone the repository.
2. Open the project in your Java Eclipse.
3. Run the `Main.java` file.

## Concepts Used
- Inheritance
- Abstraction
- Encapsulation
- Polymorphism
- Exception Handling
- Collections
- File Handling
